2611ECPC501

ASIC Design

psychology_alt Skill Gap Identified

Students need to move from RTL knowledge toward an ASIC implementation mindset: RTL → Verification → Synthesis → PPA → Timing → Physical implementation awareness.

task_alt Core Hands-on Activities (5 Units)

1
RTL Architecture Challenge Under PPA Constraints

Design parameterizable Verilog RTL modules and optimize logic depth to minimize silicon area and dynamic power dissipation.

2
Synthesis/PPA Optimization Challenge

Run logic synthesis with target cell libraries, evaluate area/power trade-offs, and insert scan chains for Design for Testability (DFT).

3
Timing Closure Challenge

Perform multi-corner static timing analysis, identify setup/hold slack violations, and resolve clock skew issues in post-synthesis netlists.

4
RTL Bug and Verification Challenge

Write self-checking SystemVerilog testbenches with assertions (SVA) and functional coverage metrics to catch corner-case design bugs.

5
End-to-End Mini ASIC Design Challenge

Execute an end-to-end RTL-to-GDSII physical design flow (Floorplanning, Power Grid, Placement, CTS, Routing, DRC/LVS) using OpenROAD / Cadence Innovus.

developer_board
Recommended Platform / Tool Cadence, Synopsys, Siemens EDA, OpenROAD, Verilog & SystemVerilog

ASIC digital design flow, logic synthesis, static timing analysis (STA), clock tree synthesis (CTS), and physical layout verification.

Professional Elective I 2611ECPE501

Testing of VLSI Circuits

psychology_alt Skill Gap Identified

The curriculum provides VLSI testing concepts. The contest/industry gap is the ability to apply testing concepts to unfamiliar digital circuits and reason about faults, coverage and test efficiency.

task_alt Core Hands-on Activities (5 Units)

1
Fault Detection Challenge

Provide an unfamiliar digital circuit with injected faults. Students must identify which faults can be detected using given test patterns.

2
Test Pattern Generation Challenge

Given a circuit and a set of possible faults, students develop test patterns that maximize fault detection.

3
Fault Coverage Optimization Challenge

Given multiple test patterns, students reduce the number of patterns while maintaining acceptable fault coverage.

4
ATPG Debugging Challenge

Provide a test-generation scenario with incomplete/ineffective test patterns. Students identify why faults are not detected and improve the test strategy.

5
Mini VLSI Testing Challenge

Teams receive an unfamiliar digital block and must: identify possible faults, propose test patterns, estimate fault coverage, and explain the test strategy.

rule
Recommended Platform / Tool Cadence, Synopsys, Siemens EDA, Open-source ATPG tools & Verilog

Automatic Test Pattern Generation (ATPG), stuck-at/transition fault grading, scan chain insertion, and test compression.

Professional Elective II 2611ECPE502

Embedded Processor

psychology_alt Skill Gap Identified

Students need to understand how to make processor-level design decisions under constraints such as performance, memory, power, instruction execution, peripheral integration, and hardware-software co-design.

task_alt Core Hands-on Activities (5 Units)

1
Processor Architecture Selection Challenge

Given an embedded application, compare possible processor architectures and select the most appropriate one based on performance, power, memory and application requirements.

2
Instruction-Level Optimization Challenge

Given an embedded task, optimize the instruction sequence to improve execution efficiency.

3
Memory Constraint Challenge

Implement an embedded application under strict memory constraints and optimize code/data usage.

4
Processor-Peripheral Integration Challenge

Integrate processor functionality with peripherals to solve an unfamiliar embedded system problem.

5
Mini Embedded Processor Challenge

Teams receive a system specification and must design a small processor-based embedded solution, demonstrate the system behavior and explain their architectural decisions.

precision_manufacturing
Recommended Platform / Tool RISC-V, RARS / Ripes, Verilog/SystemVerilog, STM32/ESP32, GCC & VS Code

Processor pipeline simulation, custom instruction decoding, memory hierarchy profiling, and bare-metal firmware optimization.

book Subject Mapped

2611ECPC502

Digital Image Processing

psychology_alt Skill Gap Identified

Students need to move from image-processing algorithms to solving real vision problems under accuracy, illumination changes, and computation constraints.

task_alt Core Hands-on Activities (5 Units)

1
Image Quality Recovery Challenge

Restore heavily degraded, low-light, or motion-blurred images using adaptive histogram equalization, Wiener deconvolution, and bilateral filtering.

2
Object/Feature Detection Challenge

Extract robust keypoints and descriptors (ORB, SIFT, Canny-Hough transforms) to detect and count objects in complex background clutter.

3
Image Segmentation Challenge

Segment target regions and defects in medical/industrial images using watershed algorithms, Otsu thresholding, and morphological operations.

4
Vision Algorithm Optimization Challenge

Optimize image processing pipelines for 60 FPS real-time execution using vectorized NumPy and OpenCV multi-threading.

5
Embedded Vision Mini Challenge

Develop a lightweight vision inspection prototype for automated defect detection on an embedded Raspberry Pi or STM32 platform.

visibility
Recommended Platform / Tool Python, OpenCV, NumPy, MATLAB & Google Colab

Image filtering, morphological analysis, feature extraction, object segmentation, and real-time video stream processing.
